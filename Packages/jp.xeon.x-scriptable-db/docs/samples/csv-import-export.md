# CSV Import/Export サンプル仕様書

## 概要

CSV/TSVファイルのインポート・エクスポート機能のサンプルです。
企画担当者やデータ管理者がExcelなどで編集したマスターデータを取り込む際の基本的なワークフローを示します。

## 学習目標

1. CSVファイルからテーブルへのインポート方法
2. テーブルからCSVファイルへのエクスポート方法
3. エンコーディングの指定方法（UTF-8, Shift-JIS等）
4. 区切り文字の切り替え（CSV/TSV）
5. Diff Viewerによる変更プレビュー

---

## データ構造

### CharacterRecord（キャラクターデータ）

| フィールド名 | 型 | 説明 | CSV列名 |
|-------------|-----|------|---------|
| id | int | キャラクターID（主キー） | ID |
| name | string | キャラクター名 | 名前 |
| level | int | レベル | レベル |
| hp | int | HP | HP |
| attack | int | 攻撃力 | 攻撃力 |
| defense | int | 防御力 | 防御力 |
| characterClass | string | 職業 | 職業 |
| isPlayable | bool | プレイアブルか | プレイアブル |

### CSV列名について

- 日本語列名を使用（企画担当者が編集しやすいように）
- `[CsvColumn("日本語名")]` 属性でマッピング

## 使用するAPI

### インポート

```csharp
// 基本的なインポート
var records = CsvParser.ParseFile<CharacterRecord>(filePath);
characterTable.SetRecords(records);

// エンコーディング指定
var records = CsvParser.ParseFile<CharacterRecord>(filePath, Encoding.UTF8);
var records = CsvParser.ParseFile<CharacterRecord>(filePath, Encoding.GetEncoding("Shift_JIS"));

// TSVの場合
var records = CsvParser.ParseFile<CharacterRecord>(filePath, "\t");

// プレビュー付きインポート（Editor）
TableImporter.ImportWithPreview(characterTable, filePath);
```

### エクスポート

```csharp
// 基本的なエクスポート
var settings = new ExportSettings
{
    FilePath = outputPath,
    Delimiter = ",",
    Encoding = Encoding.UTF8,
    SortByPrimaryKey = true
};
TableExporter.Export(characterTable, settings);

// TSVエクスポート
settings.Delimiter = "\t";
settings.FilePath = "characters.tsv";
```

## 想定するユースケース

### ユースケース1: 初期データの取り込み

1. 企画担当者がExcelでキャラクターデータを作成
2. CSVファイルとして保存（UTF-8）
3. サンプルGUIでファイルを選択
4. プレビューで内容を確認
5. インポート実行

### ユースケース2: データの更新

1. 既存テーブルをエクスポート
2. Excelで編集
3. 更新したCSVをインポート（プレビューで差分確認）
4. 必要な変更のみ適用

### ユースケース3: 多言語対応

1. 日本語環境: Shift-JIS形式のCSVを使用
2. 国際環境: UTF-8形式のCSVを使用
3. 自動検出機能でエンコーディングを判別

## 注意事項

1. **BOM（Byte Order Mark）**: UTF-8 with BOMを推奨（Excel互換性）
2. **改行コード**: CRLF/LFどちらも対応
3. **クォート**: カンマを含む値は自動的にダブルクォートで囲む
4. **エスケープ**: ダブルクォート内のダブルクォートは2重にする
5. **空値**: 空文字列はnull/デフォルト値として扱う
