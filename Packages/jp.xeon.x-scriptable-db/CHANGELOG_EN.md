## [1.1.0] - 2026-02-20

### Changed

- **ClassGenerator**: Added `_` prefix to field names (aligned with Unity coding conventions)
  - Example: `private int id;` → `private int _id;`
  - Getter/setter of properties also updated to use `_fieldName` format
- **ClassGenerator**: Automatic snake_case → PascalCase conversion for enum and user-defined type names
  - Example: `element_type` → `ElementType`
  - Type names already in PascalCase are preserved as-is

### Added

- Added unit tests for field name and type conversion in ClassGenerator

---

## [1.0.0] - 2026-02-03

### Added

#### Composite Secondary Key Index
- Implemented composite SecondaryKey index feature
  - Groups multiple fields sharing the same index name into a composite index
  - Added `Order` property to `SecondaryKeyAttribute` for specifying composite key ordering
  - Consistency check and warning for `AllowDuplicates`
- Added composite SecondaryKey search methods (`FindBySecondaryKey(indexName, params object[])` / `FindAllBySecondaryKeyAsArray(indexName, params object[])`)
- `CompositeKeyHelper` - string generation and hash computation for composite keys

#### Culture-Invariant String Conversion
- Index lookups now use culture-invariant string conversion
  - float/double: "R" format (round-trip)
  - DateTime/DateTimeOffset: "O" format (ISO 8601)
  - SerializableDateTime: Ticks value

### Fixed

- Improved handling of combined GROUP BY + JOIN operations
- Fixed bugs in aggregate functions (COUNT, SUM, AVG, MIN, MAX)
- Refactored SqlExecutor

### Changed

- Quality improvements for Unity Asset Store release
- Improved test coverage
- Documentation updates

## [0.4.0] - 2026-01-30

### Added

#### Virtual Scroll (Table Editor)
- `VirtualizedListView<T>` - virtualized list view with scroll support
  - Renders only items in the visible area
  - Smooth scrolling even with tens of thousands of records
  - Expand/collapse support
- `VirtualizedPropertyListView` - virtualized scroll list for SerializedProperty
  - Integrated into TableEditorWindow
  - Automatically uses virtual scroll for 100+ records
  - With toggle option

#### Streaming Import
- `StreamingImporter` - streaming import for large datasets
  - Chunk-based processing for memory efficiency
  - Progress display and cancel support
  - Option to continue on error
- `StreamingImportWindow` - Editor window for streaming import
  - Settings for chunk size, encoding, and delimiter
  - Real-time progress display
  - Error list display

#### Batch Processing API (Editor only)
- `BatchProcessor<TRecord, TKey>` - batch operation processor
  - `AddRange()` - bulk add multiple records
  - `UpdateRange()` - bulk update multiple records
  - `DeleteRange()` - bulk delete multiple records
  - `DeleteByKeys()` - bulk delete by keys
  - `DeleteWhere()` - bulk delete by condition
  - `UpdateWhere()` - bulk update by condition
  - `UpsertRange()` - bulk upsert multiple records
  - `ReplaceAll()` - replace all records
- `BatchOperationEntry<TRecord>` - batch operation entry
  - Supports Add, Update, Delete, Upsert operations
- `BatchProcessResult` - batch processing result
  - Added/updated/deleted/skipped/failed counts
  - Processing time
  - Error list
- Extension method `CreateBatchProcessor()` for easy creation from TableAsset

#### Benchmark Suite
- `BenchmarkTests` - performance benchmark tests
  - Search performance (linear, binary, hash)
  - Sort and filter performance
  - CSV parse and export performance
  - Memory allocation measurement
- `BenchmarkWindow` - Editor window for running benchmarks
  - Interactive benchmark execution
  - Graph display of results
  - Markdown report output

## [0.3.0] - 2026-01-29

### Added

#### Cache System
- `LruCache<TKey, TValue>` - LRU (Least Recently Used) cache
  - Capacity limit with automatic eviction
  - Hit rate and statistics tracking
- `QueryCache` - dedicated cache for query results
  - Caching by table type, query kind, and key value
  - Version-based automatic invalidation
- `CacheManager` - global cache management
  - Enable/disable cache toggling
  - Per-table invalidation

#### Lazy Loading
- `LazyTableReference<T>` - Addressables-based lazy load reference
  - Synchronous and asynchronous loading
  - Automatic release via reference counting
- `TableLoader` - batch management of multiple tables
  - Registration-based loading
  - Parallel async loading
  - Reference-count-based lifecycle management

#### Performance Profiling
- `QueryProfiler` - query execution time measurement
  - Records execution time, result count, and timestamp
  - Slow query detection
  - Cache hit tracking
- `MemoryProfiler` - memory usage estimation
  - Type size estimation
  - Per-table memory information
  - GC snapshot

#### Editor Tools
- **Performance Window** (`Window > XScriptableDB > Performance`)
  - Cache statistics display
  - Memory usage visualization
  - Query history display
  - Manual GC execution

## [0.2.0] - 2026-01-29

- `[StringLength(max)]` attribute - string length limit (with MinimumLength option)
- `[RegularExpression(pattern)]` attribute - regex pattern validation
- `[Unique]` attribute - uniqueness constraint
- `[ForeignKey(type)]` attribute - foreign key constraint

#### Editor Tools
- **Validation Window** (`Window > XScriptableDB > Validation`)
  - Table list with validation status
  - Bulk validation

## [0.1.0] - 2026-01-29

### Added

#### Core Features
- `TableAsset<TRecord, TKey>` - ScriptableObject-based table class
- `[PrimaryKey]` attribute - primary key (O(log n) search via binary search)
- `[SecondaryKey]` attribute - secondary key (O(1) search via hash index)
- `[CsvColumn]` attribute - CSV/TSV column name mapping

#### Query System
- `QueryResult<T>` - zero GC allocation ref struct query result
- `Where()`, `FirstOrDefault()`, `Any()`, `All()`, `Count()`, `Select()`, `Skip()`, `Take()` extension methods
- SecondaryKey search methods (`FindBySecondaryKey`, `FindAllBySecondaryKey`)

#### CSV/TSV Support
- CSV import/export
- TSV support
- Automatic encoding detection (UTF-8, Shift-JIS, etc.)
- BOM support

#### Editor Tools
- **Table Editor** (`Window > XScriptableDB > Table Editor`)
  - Table data editing
  - CSV/TSV import/export
  - Bulk operations

- **SQL Editor** (`Window > XScriptableDB > SQL Editor`)
  - SELECT/UPDATE/DELETE support
  - Syntax highlighting
  - Query history
  - Execute with F5/Ctrl+Enter

- **Database Browser** (`Window > XScriptableDB > Database Browser`)
  - Table list in project
  - Schema information display
  - Data preview

- **Diff Viewer**
  - Change preview before import
  - Color-coded added/deleted/modified display
  - Selective change application

#### SQL Support
- SELECT: column specification, WHERE, ORDER BY, LIMIT, OFFSET
- UPDATE: SET, WHERE
- DELETE: WHERE
- Comparison operators: =, !=, <>, <, <=, >, >=, LIKE, IN, IS NULL, IS NOT NULL
- Logical operators: AND, OR
- Grouping with parentheses

### Dependencies
- Unity 6000.0+
- com.unity.addressables 2.3.7
